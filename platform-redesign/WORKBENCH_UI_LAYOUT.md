# Workbench 화면 구획 검토

2026-10-12 요청 범위는 Studio·앱 관리 센터의 화면 구획과 목록/상세 표시다.
기존 앱 개발·등록·관리 흐름을 사용하며 시작 흐름이나 서버 권한 계약을 재설계하지 않는다.
현재 화면 동작의 소유자는 [Workbench 문서](../docs/apps/codex-console/README.md#studio앱-관리플랫폼-관리)다.

## 참고 근거

- [Lovable Dashboard overview](https://docs.lovable.dev/introduction/dashboard-overview):
  프로젝트를 이름과 상태가 있는 카드로 표시하고 프로젝트별 연관 행동을 묶는다.
- [v0 Projects](https://v0.app/docs/projects): 프로젝트 탐색과 프로젝트 설정을 구분한다.
  이름·선택 문맥을 유지하며 해당 프로젝트의 세부 정보를 다룬다.

Workbench 공통 사이드바 하나만 사용한다. 본문의 가로 탭과 카드 목록에서 항목을 열면
본문 전체 폭의 상세로 전환하며, 상세의 관련 정보는 제목과 구분선으로 묶는다.
실제 미리보기 썸네일이 없는 앱에 가짜 미리보기나 게시 상태를 만들지 않는다.

## 로컬 확인 범위

`e2e/app-browser.spec.ts`는 별도 테스트 서버와 합성 카탈로그를 사용해 프로젝트 선택/URL 복원,
추가 사이드바 없음·카드 그리드·목록/상세 전환, 앱 상세의 명명된 섹션, 모바일 목록 복귀/카드 포커스,
검색 결과 없음/복구 및 탐색 중 쓰기 요청 부재를 확인한다. 화면 산출물은 테스트 결과에 저장한다.
기존 Workbench Vitest와 빌드/타입 검사를 함께 사용한다.

## r23 배포 기록

사용자의 배포 요청으로 별도 Workbench `20261012-studio-layout-r23`을 설치했다.
기준 소스는 `b13a75741d16a83955ca928d50a548abace5c7b7`이며 이번 UI 수정은 미커밋 상태를 포함한다.
릴리스 식별자는 `source_dirty=true`, digest는
`sha256:81a48e22257b36b8dc821a9589697248ecde5ea27cdeb4a570bde8d68db606ac`다.

- 이전 r22와 비교해 UI 밖의 릴리스 입력은 동일하다. DB migration은 없다.
- 진행 중 root/하위 작업과 자원 lease가 없는 상태에서 공식 SQLite online backup과 무결성 검사를 수행했다.
- session/management 두 서비스의 실제 실행 경로가 r23이며, template-current와 템플릿 서비스 PID를 보존했다.
- 기존 저장 내용의 해시와 작업 19개·프로젝트 1개·작업 환경 1개·템플릿 14개를 보존했다.
- 직접 세 역할과 공개 `/healthz`가 정상이며, 공개 JS/CSS 바이트가 새 릴리스와 일치한다.
  공개 Studio/앱 관리 URL의 로그인 화면, 스크립트 로딩, 브라우저 오류 없음, 모바일 폭을 확인했다.

전체 단위 테스트 238개와 관련 브라우저 검사 9개, 빌드/타입·생성 계약·번역·웹 구조 검사가 통과했다.
기존에 저장된 실제 로그인 세션은 만료되어 인증 후 운영 화면 검증은 수행하지 못했다.
합성 데이터로 수행한 로컬 화면 검사를 실제 로그인 인수로 해석하지 않는다.
배포·백업 영수증과 공개 확인 결과는 비공개 `.runtime/studio-ux/deployment/`에 보존한다.

## 단일 사이드바 수정

r23의 두 번째 탐색 사이드바에 대한 사용자 지적으로, 위의 본문 카드 목록/상세 화면으로 수정했다.
초기 프로젝트 자동 선택도 제거하여 실제 프로젝트 목록을 첫 화면에 표시한다.
전체 단위 테스트 238개·관련 브라우저 검사 9개·등록 승인 검사 3개, 빌드/타입·번역·웹 구조 검사가 통과했다.
데스크톱 Studio/앱 관리와 모바일 캡처를 검토했다. 별도 운영 전환 근거는 비공개
`.runtime/studio-ux/single-menu-deployment/`에 기록한다.

수정본 `20261012-studio-gallery-r24`를 별도 Workbench에 설치했다. 기준 소스와 미커밋 상태 표시는
r23과 같으며 새 digest는 `sha256:c6489ef06f85e1cca05773f242f9169b47e7b0134ae4c80f2bb2ea4795929853`다.
비 UI 릴리스 입력은 r23과 동일하다. 공식 SQLite 백업·무결성·저장 내용 보존, 두 서비스의 실제 r24 실행 경로,
템플릿 서비스와 template-current 보존을 확인했다. 공개 주소가 새 JS/CSS와 카드 목록 스타일을 제공하고
직접·공개 health check가 통과했다. 인증 후 운영 화면 검증의 한계는 r23과 동일하다.
