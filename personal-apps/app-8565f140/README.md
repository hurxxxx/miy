# 장비·비품 관리

본인 계정의 장비 이름, 관리번호, 사용자, 위치와 사용/보관 상태를 등록·수정·검색합니다. 빈 목록에서 가짜 예시 2개를 선택적으로 추가할 수 있습니다. 관리번호는 등록 후 변경할 수 없습니다.

## 저장 연결

`web-api-postgres-v1` 및 `identity:read`, `data:read`, `data:write` 설치 권한이 필요합니다. 앱 매니페스트 변경만으로 연결이나 권한이 생기지는 않습니다. 플랫폼이 제공하는 사용자별 비공개 레코드 저장만 사용합니다. 팀 공유나 실제 직원 명부 연동은 제공하지 않습니다.

## 검증 명령

- `pnpm test`
- `pnpm build`
- `python -m unittest discover -s tests -p 'test_*.py'`

API 테스트는 가짜 플랫폼 gateway로 인증 전달, 입력 검증, 중복, 수정 충돌과 사용자별 분리를 확인합니다. 실제 저장 연결, 재접속 후 유지, 브라우저 세션 교환은 연결된 개발 설치에서 별도 확인해야 합니다. 배포는 신뢰된 플랫폼 릴리스 서비스를 통해 별도로 진행합니다.

플랫폼 계약은 [PLATFORM_CAPABILITIES.md](PLATFORM_CAPABILITIES.md)를 참고하세요.
